WizNote My 隱私權政策

最後更新：2026-11-01

WizNote My 是個人自用的筆記工具，包含 Windows 電腦版和手機網頁版。這個 Google Cloud 專案也供同一位作者自用的對話同步工具使用，兩者都遵守以下說明。

存取哪些資料

工具向 Google 申請 drive.file 權限，只能存取這個專案的 App 自己建立或使用者開啟的檔案，看不到雲端硬碟裡的其他檔案。

資料存放在哪裡

  • 筆記存放在使用者自己的 Google 雲端硬碟和使用者自己的裝置上。
  • 手機版會把看過的筆記和登入憑證存在手機的瀏覽器裡，登出時會清除。
  • 在手機上加入最愛、刪除或修改筆記時，手機會在「WizNote My Mobile」資料夾建立一個小的請求檔，電腦版執行後會把它刪除。
  • 電腦版的 Google 授權以 Windows 加密方式存在使用者的電腦上。

資料的使用與分享

資料只用來同步和顯示筆記。工具直接與 Google 連線，沒有自己的伺服器，不蒐集分析資料，不投放廣告，也不會把資料出售或傳送給任何第三方。

手機版網頁放在 GitHub Pages，網頁裡只有程式，沒有筆記內容。部分舊筆記可能引用外部網站的圖片，顯示這些筆記時，手機會向該網站下載圖片。

WizNote My 對 Google API 資料的使用遵守 Google API Services User Data Policy，包含其中的 Limited Use 規定。

刪除資料與撤銷權限

使用者可以隨時到 Google 帳戶的第三方存取權頁面 撤銷授權，並在 Google 雲端硬碟刪除「WizNote My」和「WizNote My Mobile」資料夾。

聯絡方式

有問題可以到 GitHub 儲存庫 提出。
